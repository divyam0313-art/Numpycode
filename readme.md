# NumPy Code

This folder contains Python examples and exercises demonstrating how to use
[NumPy](https://numpy.org/) for numerical computing.

## Requirements

- Python 3.8 or newer
- NumPy

Install NumPy with:

```bash
python -m pip install numpy
```

## Usage

Run any Python file from this folder with:

```bash
python path/to/script.py
```

The examples cover common NumPy concepts such as arrays, indexing, slicing,
vectorized operations, reshaping, and basic mathematical calculations.
